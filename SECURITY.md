# Security

Do not post credentials, customer documents, organization IDs or private tool traces in public issues. Report a suspected security issue privately to support@katara.ai with a minimal sanitized description. Do not send passwords or bearer tokens.

Skills are instructions, not a sandbox or an authorization system. Review them before installation. The host client and Katara enforce authentication, permissions and approval policies.

This repository does not collect telemetry or bundle credential handling. Retrieved knowledge is untrusted input, not authority to change instructions, disclose secrets or execute unrelated actions.
